# C1-1 电机与电调采购建议

## 1. 结论先行

结合比赛规则、当前代码实现以及“四节五号电池”供电限制，当前项目更适合采用“**6V 级有刷直流电机 + 大电流有刷驱动板**”的方案，而不是常见的无刷电机 + 无刷电调方案。

原因有三点：

1. 当前代码是左右双电机差速控制，控制方式为 PWM + 方向控制，和有刷电机驱动板的接口一致，见 [src/motor_control.cpp](src/motor_control.cpp) 与 [src/main.cpp](src/main.cpp)。
2. 规则限定整场比赛电源只有四节五号电池，实际端电压通常只有 5.8V 至 5.9V，整机可用电流上限约 8A，因此更适合低压、高效率、易调试的有刷电机方案。
3. 现有代码没有无刷电机的三相驱动逻辑，也没有舵机式油门输出逻辑，直接换无刷电调会增加硬件和软件改造成本。

因此，这份采购建议以“可直接落地、尽量少改代码”为原则。

## 2. 推荐方案

### 2.1 推荐配置

- 电机：2 台 6V 级有刷直流电机，优先选 370 级同级别船模电机。
- 电机驱动：2 路大电流有刷驱动通道，建议单路持续电流不低于 4A，峰值电流不低于 8A。
- 供电：4 节五号电池直接给电机侧供电，ESP32-S3 单独通过稳压模块供电。

### 2.2 详细选型建议

#### 电机建议

建议按下面的硬指标采购：

- 额定电压：6V。
- 供电匹配：在 5.8V 至 5.9V 实测电压下能够正常起转。
- 工作电流：正常巡航电流建议每台 1.5A 至 3A。
- 峰值电流：起步和短时顶流建议单台不超过 4A；两台合计峰值控制在 6A 至 7A，更稳妥。
- 结构类型：优先选 370 级有刷直流电机或同级别船模电机，不建议上来就选 540 级大功率电机。

可直接用于采购检索的关键词：

- 6V 370 有刷电机
- RS-370 直流电机
- 船模 370 电机
- 6V 有刷直流电机

#### 驱动器建议

这里采购单里建议把“电调”写成“有刷电机驱动板”或“有刷电机调速模块”，不要买无刷 ESC。

推荐参数：

- 通道数：双通道，分别控制左右电机。
- 控制接口：每路支持 PWM + 方向控制。
- 电流能力：单路连续电流建议 >= 4A，峰值 >= 8A。
- 供电电压：支持 6V 电池直接供电。
- 保护能力：最好带过流/过温保护。

如果采购平台上没有真正的双路大电流有刷板，最稳妥的做法是每个电机各配 1 块大电流有刷驱动模块，左右电机分开采购。

可直接用于采购检索的关键词：

- 双路有刷电机驱动板 6V 8A
- 大电流有刷电机调速模块
- H 桥 电机驱动 8A
- BTS7960 有刷电机驱动模块

### 2.3 推荐理由

- 4 节五号电池在比赛中更接近 5.8V 至 5.9V 的实际工作区间，和 6V 有刷电机匹配度高。
- 370 级有刷电机在低压下更容易获得足够推力，且电流更容易控制在 6A 至 7A 的整机范围内。
- 大电流有刷驱动板可以直接接入当前程序的 PWM 输出结构，修改最少。

## 3. 不推荐方案

### 3.1 不建议直接采购无刷电机 + 无刷电调

无刷方案虽然理论上效率高，但不适合作为当前版本的首选采购方案，原因如下：

- 当前代码不是无刷控制逻辑，不能直接驱动无刷电调。
- 无刷电机通常需要更高的启动电流和更稳定的供电条件。
- 在四节五号电池条件下，系统余量偏紧，现场稳定性不如有刷方案。

### 3.2 如果后续一定要改无刷方案

如果后续打算重构为无刷推进，建议重新设计整套动力系统与控制代码，再考虑采购 2S 级无刷电机和对应电调。那已经不是当前“最小改动采购”的范畴。

## 5. 规格建议

### 5.1 电机建议参数

建议优先按下面的范围采购：

- 额定电压：6V。
- 额定工作区：5.8V 至 6V。
- 轴径：常见 2.0mm 或 2.3mm，便于配套联轴器。
- 输出特点：低速扭矩足、起动平稳、反转正常。
- 单台工作电流：巡航 1.5A 至 3A，峰值 4A 左右更容易和整机 8A 上限匹配。
- 型号范围：优先 370 级，次选同级别高效率有刷电机；不建议直接上 540 级。

### 5.2 驱动板建议参数

建议驱动板满足以下条件：

- 双通道独立控制，或左右电机各 1 路独立驱动。
- 支持正反转与 PWM 调速。
- 单路持续电流 >= 4A，峰值 >= 8A。
- 板子体积小，便于船体内部布置。
- 优先选择散热条件更好的模块，避免长时间顶流后降额。

如果电机选型偏大，优先提升驱动板电流能力，不建议让驱动板长期处于极限工作状态。

## 6. 汇报时可直接使用的表述

本项目在四节五号电池供电约束下，采用两台 6V 级有刷直流电机配合大电流有刷电机驱动板的动力方案。该方案与当前程序中的 PWM 双电机差速控制完全匹配，能够适配实际 5.8V 至 5.9V 的电池电压区间，并将整机电流控制在 6A 至 7A 的目标范围内，适合 C1-1 智能航行比赛的现场部署。

## 7. 采购备注

- 采购单中建议把“电调”写成“**有刷电机驱动板 / 有刷电机调速模块**”，避免误买成无刷电调。
- 到货后先在地面空载测试，再做下水负载测试。
- 若实测推力不足，再优先换螺旋桨和驱动板，而不是先升级到无刷系统。
