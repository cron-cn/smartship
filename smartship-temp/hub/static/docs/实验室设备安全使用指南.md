# 实验室设备安全使用指南

## 目的
为保障人员与设备安全，规范实验室设备（含电子设备、充电器、动力电池、工具等）的使用、充电与存放行为，降低电气事故与设备损坏风险。

## 一般遵守原则
- 使用前确认设备外观、线缆与插头无破损。发现破损或异常立即停止使用并上报。 
- 任何时候保持专注，避免在通话、饮酒或疲劳状态下操作电气设备。 
- 使用符合额定电压与电流的电源与线缆，杜绝私拉乱接或临时改装电路。 

## 使用前检查（每次使用）
- 检查电源线、插头、插座是否有裂痕、发黑或接触不良现象。
- 确认设备铭牌上的额定电压/电流与实验室供电相匹配。
- 检查周边是否有易燃物、潮湿或金属杂物，必要时清理后再开机。

## 使用中注意事项
- 不超负荷：同一排插上连接设备总功率不得超过排插与回路额定值。
- 排插就位：尽量使用品牌合格、有过载保护的插排；不要把排插叠压、覆盖在织物下或靠近热源。
- 电池/动力模块管理：使用中的船舶电池、动力电池应放置在有围挡和通风的区域，严禁在可燃材料旁充电。
- 远离水汽：潮湿环境会增加触电或短路风险，实验台面保持干燥。

## 使用后（离开/收尾）
- 关断电源：使用结束或离开实验室时，请务必关闭设备电源并拔掉不必要的插头。
- 船舶电池与电源插座：出门或下班前务必关闭船舶电池主开关与排插电源；对于带有隔离开关的设备，切断总电源。 
- 规范存放：电池请按类别分类存放（干电池、铅酸、锂电池分区），保持干燥、通风，远离直射阳光和高温。

## 充电安全
- 仅使用厂家推荐或经过验证的充电器；充电过程中避免无人看守大功率电池。
- 充电区应有耐火托盘或金属隔离托架，远离易燃物并保持通风。
- 发现电池异常（膨胀、冒烟、异味、发热）立即切断电源并移至空旷处或按应急流程处理，禁止用水直接扑灭锂电池火情，应使用适当灭火器材。

## 维护与报修
- 定期对设备进行检查与保养，记录检查结果与发现的问题。
- 非专业人员不得拆解高压或大电流设备，需联系指定管理员或厂家维修。

## 应急与上报
- 发现火情、冒烟或明显电气异常，第一时间切断电源并启动应急程序；必要时拨打火警电话并疏散人员。
- 发生触电、烧伤等人员伤害，立即按急救流程处理并报告实验室负责人。

---
**保持谨慎、规范操作，是预防事故的第一道防线。**
