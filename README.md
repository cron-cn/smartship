# 项目简介

本仓库包含一个用于管理与展示实验室设备信息的轻量程序（位于 `hub/`）。本 README 提供程序的使用方法与部署步骤，并将实验室安全使用与用电消防指南一并纳入，方便统一查看。

**主要内容：**
- 程序运行与安装步骤
- 实验室设备安全使用指南（内嵌）
- 实验室消防与用电安全（内嵌）

---

## 快速开始（Windows）

1. 克隆仓库或在本地打开项目目录。
2. 建议创建 Python 虚拟环境并激活：

```powershell
python -m venv venv
.\n+# 激活（PowerShell）
.\venv\Scripts\Activate.ps1
# 或使用仓库提供的脚本（如果想自动设置环境）
.\start_env.bat
```

3. 安装依赖：

```powershell
pip install -r hub/requirements.txt
```

4. 启动程序：

```powershell
python run_app.py
# 或者直接运行 hub 内的 Flask 应用：
python -m hub.app
```

5. 测试（可选）：

```powershell
pytest test_e2e.py
```

说明：如果您使用其他操作系统或有特殊虚拟环境管理策略，请按相应平台的虚拟环境与激活方式调整第 2 步。

---

## 使用流程与操作步骤

1. 准备环境并安装依赖（见上）。
2. 启动应用后在浏览器打开本地服务地址（默认在控制台输出，或检查 `hub/app.py` 中的配置）。
3. 在 Web 界面中浏览分类、设备详情，或使用 API（如已提供）进行集成。
4. 如需添加/编辑设备数据，可以在 `hub/data/` 下的对应 `devices/` 或 `categories/` 目录中更新 JSON 文件，并重启服务以加载最新数据。

## 实验室设备安全使用指南

# 实验室设备安全使用指南

## 目的
为保障人员与设备安全，规范实验室设备（含电子设备、充电器、动力电池、工具等）的使用、充电与存放行为，降低电气事故与设备损坏风险。

## 一般遵守原则
- 使用前确认设备外观、线缆与插头无破损。发现破损或异常立即停止使用并上报。 
- 任何时候保持专注，避免在通话、饮酒或疲劳状态下操作电气设备。 
- 使用符合额定电压与电流的电源与线缆，杜绝私拉乱接或临时改装电路。 

## 使用前检查（每次使用）
- 检查电源线、插头、插座是否有裂痕、发黑或接触不良现象。
- 确认设备铭牌上的额定电压/电流与实验室供电相匹配。
- 检查周边是否有易燃物、潮湿或金属杂物，必要时清理后再开机。

## 使用中注意事项
- 不超负荷：同一排插上连接设备总功率不得超过排插与回路额定值。
- 排插就位：尽量使用品牌合格、有过载保护的插排；不要把排插叠压、覆盖在织物下或靠近热源。
- 电池/动力模块管理：使用中的船舶电池、动力电池应放置在有围挡和通风的区域，严禁在可燃材料旁充电。
- 远离水汽：潮湿环境会增加触电或短路风险，实验台面保持干燥。

## 使用后（离开/收尾）
- 关断电源：使用结束或离开实验室时，请务必关闭设备电源并拔掉不必要的插头。
- 船舶电池与电源插座：出门或下班前务必关闭船舶电池主开关与排插电源；对于带有隔离开关的设备，切断总电源。 
- 规范存放：电池请按类别分类存放（干电池、铅酸、锂电池分区），保持干燥、通风，远离直射阳光和高温。

## 充电安全
- 仅使用厂家推荐或经过验证的充电器；充电过程中避免无人看守大功率电池。
- 充电区应有耐火托盘或金属隔离托架，远离易燃物并保持通风。
- 发现电池异常（膨胀、冒烟、异味、发热）立即切断电源并移至空旷处或按应急流程处理，禁止用水直接扑灭锂电池火情，应使用适当灭火器材。

## 维护与报修
- 定期对设备进行检查与保养，记录检查结果与发现的问题。
- 非专业人员不得拆解高压或大电流设备，需联系指定管理员或厂家维修。

## 应急与上报
- 发现火情、冒烟或明显电气异常，第一时间切断电源并启动应急程序；必要时拨打火警电话并疏散人员。
- 发生触电、烧伤等人员伤害，立即按急救流程处理并报告实验室负责人。

## 实验室消防与用电安全

# 实验室消防与用电安全

## 目标
预防电气火灾与用电事故，明确日常用电规范、火险隐患识别与应急处置要点，保障人员与财产安全。

## 用电安全要点
- 负载管理：不要在单一路由或排插上并联过多高功率设备，合理分配负载，遵循电源额定值。 
- 合格器材：使用有认证标志的插座、排插与延长线；排插应带漏电/过载保护优先。 
- 插拔规范：插拔电源前先关闭设备电源，插头插拔时握住插头本体，不要拉扯线缆。
- 配电检查：定期查看配电箱、漏电保护器与开关状态，有异常及时联系电工。

## 火源与易燃物管控
- 禁止在实验室内存放大量易燃液体（如溶剂、汽油等），如确需存放应使用指定防火柜并标记清楚。
- 电池充电与存放应与易燃材料隔离，电池仓应保持通风与温度可控。

## 电池及动力电源管理（包括船舶电池）
- 充电位置：充电时放在耐火托盘或专用充电台，充电过程尽量有人值守；禁止将正在充电的电池放入密闭可燃箱内。
- 下班/走人时：务必切断船舶电池与大功率电源的主开关，拔掉非必要插头，确保无人值守时无电源负荷。
- 漏电与短路：定期检查电池端子与连接线，防止接触不良导致发热或火花。

## 灭火与应急设备
- 灭火器：实验室应配备适合电气火灾的灭火器（如干粉或 CO2），并张贴使用说明。 
- 应急照明与疏散通道：保持疏散通道畅通，应急照明保持可用并定期检查。
- 应急联络：张贴紧急联系电话（消防、保安、负责人），并确保所有使用者知晓。

## 火险发生时的基本处置顺序
1. 迅速评估安全撤离路线，优先撤离人员至安全地带并拨打火警；
2. 如能安全切断电源，应先切断受影响设备电源；
3. 小范围电气火情在确认安全的情况下使用电气类适用灭火器扑灭；
4. 若火势无法控制，立即撤离并等待专业救援，不要冒险扑救。

## 例行检查建议（周/月）
- 每周：检查实验台、插排、明显线缆磨损，确保无烟味或发热痕迹。
- 每月：检查配电箱及漏电保护器功能；核对灭火器压力表与有效期。

---

保持良好用电习惯与日常检查，是避免火灾和电气事故的关键。
