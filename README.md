# C1-1 便携仿真包

这个文件夹用于把比赛模拟程序单独打包，便于拷贝到别的电脑上直接运行。它既可以做图形演示，也可以做命令行回放和日志归档。

## 目录结构

- `tools/race_simulation.py`：命令行仿真核心，输出船体状态、目标门预测和过门结果。
- `tools/race_simulation_gui.py`：图形化仿真界面，支持拖动光电门、查看预测、导出日志和导入复现文件。
- `启动图形仿真.bat`：优先使用本地 `.venv`，否则尝试系统 Python，启动图形界面。
- `启动命令行仿真.bat`：启动命令行演示，用于查看文本输出和调试过程。
- `创建环境.bat`：如本机没有可用 Python 环境，可自动创建 `.venv`。
- `requirements.txt`：便携包依赖说明，目前至少需要 Pillow。
- `logbook/`：日志导出目录，每次导出会生成一个独立子文件夹。

## 运行前准备

1. 如果电脑已经安装 Python 3.13 或兼容的 Python 3.x，可以直接双击启动脚本。
2. 如果你希望使用独立环境，请先运行 `创建环境.bat`。
3. 如果要使用图形界面的“导出日志”功能，请确认 Pillow 已安装。

## 启动方式

### 图形界面

双击 `启动图形仿真.bat`。

这个脚本会按以下顺序寻找 Python：

1. 先使用本目录下的 `.venv\Scripts\python.exe`
2. 再尝试 `py -3`
3. 最后尝试系统 `python`

如果前面的环境可用，就会直接进入 GUI。

### 命令行演示

双击 `启动命令行仿真.bat`。

这个模式适合看文字输出、检查每一步过门预测，或者在没有图形界面的电脑上快速验证模拟结果。

## 图形界面功能说明

图形界面主要用于可视化赛道和船模运行状态，左侧显示场地，右侧是控制面板。

### 赛道与门

- 支持初赛 3 门和决赛 10 门两种预设。
- 可以在画布空白处左键新增光电门。
- 可以拖动光电门调整位置。
- 可以双击光电门删除。
- 赛道长度可调，范围是 30 到 150 米。
- 赛道宽度可调，范围是 0 到 150 米，设置为 0 时会自动适配。

### 仿真控制

- “开始 / 暂停”：开始或暂停船模运行。
- “单步推进”：在暂停状态下前进一步。
- “重置仿真”：把船体状态和运行过程清回初始值。
- “加载预设赛道”：切换初赛 3 门或决赛 10 门布局。
- “清空光电门”：删除所有门，方便从零布置。
- “切换编辑模式”：控制是否允许继续拖动和放置门。
- “切换全屏”：切换窗口全屏显示。

### 可视化开关

- “显示红外发射圆锥”：显示或隐藏门上的发射范围。
- “显示船载红外感应”：显示或隐藏船体上的感应范围。

### 状态显示

右侧状态栏会给出以下信息：

- 当前运行时间
- 当前目标门
- 过门预测结果
- 当前通过进度
- 门尺寸是否符合规则

## 日志导出说明

点击“导出日志”后，程序会在 `logbook/` 下创建一个新的独立子文件夹。每次导出都会生成一份完整记录，便于归档、汇报和复现。

每个导出文件夹中通常会包含下面三类文件：

- `scene.jpg`：当前画布截图，用于查看赛道和船模当时的可视化状态。
- `report.md`：文字报告，包含总成绩、过门时间、门结果和关键状态。
- `replay.json`：复现文件，保存赛道、光电门、船体状态、轨迹和门结果。

### 报告内容

报告里会尽量记录以下信息：

- 保存时间
- 赛制模式
- 赛道长度和宽度
- 总门数、已通过、已失败、未处理
- 总用时和平均门耗时
- 每个门的时间、坐标和横向偏差
- 当前运行事件记录

## 复现文件说明

`replay.json` 是最重要的复现文件。它不仅保存门的位置，还保存了当前船体状态和仿真过程中的关键数据，因此可以用来恢复当时的运行现场。

导入后通常会恢复这些内容：

- 赛道长度和宽度
- 当前布置的光电门
- 船体位置、航向和速度
- 已经过门的记录
- 轨迹点
- 显示开关状态

导入方法是点击“导入复现文件”，然后选择对应的 `replay.json`。

## 适合的使用场景

- 比赛演示时做现场讲解。
- 赛道布置后保存一份现场快照。
- 调整参数后做对比分析。
- 把同一组赛道发给其他电脑复现。

## 常见问题

### 打不开图形界面

先确认电脑上是否有 Python。如果没有 Python，请先安装 Python 3.13，再运行 `创建环境.bat`。

### 导出日志失败

通常是因为 Pillow 没有安装，或者当前环境无法抓取窗口截图。此时先确认依赖安装正确，再重新启动程序。

### 导入后显示和原来不一致

请确认导入的是同一次导出的 `replay.json`，不要手动改动文件内容。如果修改过文件，复现结果可能不同。

## 建议

如果你要把这个目录发给别人，建议整个 `portable_race_simulation` 文件夹一起压缩后发送。这样对方可以直接运行，也能带上日志归档目录和依赖说明。
